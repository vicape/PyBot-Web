# Lo más fácil: GitHub Desktop (sin comandos git)

**Vos** tenés que hacer 3 clics en el navegador para entrar con Google. Desde acá nadie puede entrar a tu cuenta.

## Paso 1 — Instalar GitHub Desktop

1. Abrí: https://desktop.github.com/  
2. Descargá e instalá (siguiente, siguiente).

## Paso 2 — Entrar con tu cuenta (Google)

1. Abrí **GitHub Desktop**.  
2. **Sign in to GitHub.com** → se abre el **navegador**.  
3. Entrá como siempre (**Sign in with Google**).  
4. Volvé a GitHub Desktop cuando diga que ya estás conectado.

## Paso 3 — Publicar PyBot-Web

1. En GitHub Desktop: **File → Add Local Repository**.  
2. **Choose…** y seleccioná la carpeta:  
   `C:\Users\Naro\PyBot-Web`  
3. Si dice que no es un repositorio git, tocá **“create a repository”** ahí mismo (nombre `PyBot-Web`, sin ignorar cosas raras).  
4. Arriba: **Publish repository** (o “Publicar”).  
5. Dejá **Name: PyBot-Web**, marcá **Keep this code private** si querés, y **Publish**.

Listo: el código ya está en GitHub. Después en **Vercel** importás ese repo y deploy.

---

### Si ya usaste `git init` en la terminal

No pasa nada: GitHub Desktop detecta la carpeta igual. Si hay líos, en Desktop: **Repository → Repository Settings → Remote** y revisá la URL.
